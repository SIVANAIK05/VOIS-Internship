 # Employee Attrition Analysis

## Project Overview

Employee attrition is an important challenge for organizations, as understanding why employees leave can help improve employee retention and workplace conditions.

This project focuses on analyzing employee attrition using Python and Exploratory Data Analysis (EDA) techniques. The analysis examines different employee-related factors and identifies patterns associated with employee attrition.

This project was completed as part of the **VOIS Internship**.

---

## Objective

The main objectives of this project are:

- Understand the structure of the employee attrition dataset.
- Explore employee-related data using Python.
- Perform statistical and exploratory analysis.
- Identify missing values and data quality issues.
- Analyze factors related to employee attrition.
- Generate visualizations to understand patterns in the data.
- Derive meaningful insights from the analysis.

---

## Dataset

The project uses the **Attrition Analytics** dataset in CSV format.

### Dataset Details

- **Rows:** 1,480
- **Columns:** 38
- **File:** `Attrition_Analytics.csv`
- **Target Variable:** `Attrition`

The dataset contains employee-related information such as:

- Age
- Business Travel
- Department
- Education
- Education Field
- Job Role
- Job Satisfaction
- Monthly Income
- Overtime
- Work-Life Balance
- Total Working Years
- Years at Company
- Years in Current Role
- Years Since Last Promotion
- Years With Current Manager
- Attrition
